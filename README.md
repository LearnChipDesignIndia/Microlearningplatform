# Telegram MicroLearn Bot

Free daily technical learning platform using Telegram + Google Apps Script.

## Setup

1. Create Telegram bot via @BotFather
2. Create Google Sheet with tabs: Users, Topics, MessageLog, Config
3. Deploy Code.gs as Web App
4. Run setWebhook() function
5. Add your BOT_TOKEN to Config sheet

## Features

- 30-day learning tracks
- Daily automated lessons
- Quiz interactions
- User progress tracking
- Free trial version

## Deployment

- Apps Script: `Code.gs`
- Database: Google Sheets
- Scheduler: Apps Script Triggers (9 AM IST daily)

## Topics Included

- AMBA AXI4 Protocol
- RISC-V Base Integer ISA
- PCIe Gen5 Layering
- SystemVerilog Fundamentals
